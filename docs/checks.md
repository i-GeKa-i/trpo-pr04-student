# Результаты проверок

Окружение: PHP 8.4, встроенный сервер, `error_reporting(E_ALL)` на localhost. PHP warning/notice на страницах не появились.

## Автопроверка `php tests/check_cases.php`

Вход → ожидаемый результат (`dataset/form_cases.json`):

| case | вход | ожидалось | итог |
|---|---|---|---|
| empty_name | name="", experience=2 | ошибка | OK |
| bad_experience | name="Иван", experience=-2 | ошибка | OK |
| valid | name="Иван", experience=4 | без ошибок | OK |

Дополнительно: пробелы вместо имени, email `abc`, стаж `abc` — ошибки; фильтр «Разработка» → 2 строки, пустой фильтр → 5 строк. Всё OK.

## Ручные сценарии (HTTP-запросы к встроенному серверу)

| сценарий | результат |
|---|---|
| `GET /` | 5 сотрудников, ошибок нет |
| `GET /?department=Поддержка` | 1 сотрудник |
| `POST` name=`<b>x</b>`, email=`bad`, отдел пуст, стаж `-2` | 3 сообщения у полей (email, отдел, стаж), значения сохранены, `<b>` экранирован (`&lt;b&gt;`) |
| `POST` корректные данные | «Заявка принята», запись сохранена в `data/applications.json` |
